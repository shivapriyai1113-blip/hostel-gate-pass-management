# Hostel Gate Pass Management System

A frontend-only project prototype built with HTML, CSS and JavaScript.

## Run
1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Open `index.html` in a modern browser.
3. Navigate using the left menu.

## Included demo features
- Dashboard summary and recent requests
- Student gate pass request form with date/time validation
- Request list with simulated approve/reject actions
- Security verification by pass ID
- Notifications
- Browser `localStorage` persistence

## Important limitations
This is a frontend demonstration only. It has no real login, server, or shared database. Approval controls are for demonstration and are not role-protected. Do not use it to make real hostel entry decisions. A production system needs a backend, database, authentication, authorization, and audit logging.
